# Copy Quant detail

## User and task

The owner checks the latest Copy Trading wallet balance, daily fetch/validation quality, and the recommendations and public performance of tracked lead traders.

## Required truth

- Unlock with the same passphrase as the Stock Port report; decrypt only in the browser.
- Show snapshot age and incomplete/missing source warnings.
- Label ROI and performance as lead performance; it is not copier PnL.
- Treat hidden positions as unknown, not flat.
- Do not imply trades are executed by the report.

## Structure and visual system

The route shares the Deep Current full-width top navigation and dark observatory system. Lead details remain readable on mobile and keep each recommendation beside its evidence.
